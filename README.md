# 🎬 MovieRecs - Recomendador de Películas

**MovieRecs** es una aplicación web que te recomienda películas basadas en tus gustos y te permite dejar comentarios o reseñas sobre ellas.  
Ideal para los amantes del cine que buscan descubrir nuevas historias y compartir sus opiniones.

---

## 🚀 Características principales

- 🔍 **Recomendaciones personalizadas** según género, año o popularidad.  
- 💬 **Sección de comentarios** para dejar tu opinión sobre cada película.  
- ⭐ **Valoración con estrellas** para calificar las películas.  
- 🧠 **Sistema inteligente de sugerencias** basado en tus elecciones anteriores.  
- 📱 **Diseño responsive**, adaptable a celulares, tabletas y computadoras.
